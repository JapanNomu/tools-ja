# user_knowledge/

このフォルダは、**あなた自身のノウハウファイル（.md）を置く場所**です。

## 使い方

1. このフォルダに `.md` 形式のノウハウファイルを配置する（カテゴリごとにサブフォルダを作ってもOK）
2. `src/venv/bin/python3 src/knowledge_src/split_knowledge.py` を実行する
   - このフォルダの `.md` がH2見出しごとに分割され、`knowledge/user_chunks/` に出力される
3. `src/venv/bin/python3 src/knowledge_src/import_knowledge.py` を実行する
   - `user_chunks/` の分割ファイルが Cognee に投入される

## ファイル形式の推奨

- マークダウン形式（`.md`）
- H1（`# タイトル`）でファイル全体のテーマを示す
- H2（`## セクション名`）で章を区切る（分割の単位になる）
- H3以下は自由

## なぜ分割するのか

Cognee の cognify（LLMによる要約・グラフ化）処理は、**大きいファイル（数百行）でLLMが要約失敗（status=errored）することがあります**。
これを避けるため、H2見出しごとに分割して投入しています。

各分割ファイルには、元ファイルへの参照情報が冒頭に付与されるため、グラフ記憶として引き出した時に元ドキュメントを辿れます。

## 注意

- このREADME.mdは投入対象外です（split時・import時に自動でスキップされます）
- フォルダ構成は自由ですが、深いネストよりカテゴリ別の浅いフォルダを推奨します
